# Калькулятор сходів / Calculadora de escaleras

Автор / Autor: **Anatolii Serediuk** · версія 1.1

## Як зібрати (Android Studio)
1. **File → Open** → папка `StairCalculator`.
2. **Gradle JDK = jbr-17 або jbr-21** (File → Settings → Build Tools → Gradle). Java 25 НЕ підходить.
3. Дочекайся Gradle Sync (потрібен інтернет), далі **Run ▶** на телефоні або емуляторі.
4. APK: **Build → Build APK(s)**.

minSdk 26 (Android 8.0+), Kotlin 2.0.20, Jetpack Compose, Room, Gradle 8.11.1.

## Як користуватись
- Обов'язково: **висота** і **довжина**. Вони не змінюються (допуск ±1 см показується в «Відхилення»).
- Необов'язково: глибина сходинки, висота сходинки, товщина, довжина сходинки (ширина сходів).
- Г-подібні: додаткове поле «Довжина другого напрямку».
- П-подібні: довжина = довжина маршу + ширина площадки; ширина по площині = 2 × ширина сходів.
- Натисни **Розрахувати** — з'являться кількість сходинок, висота й глибина сходинки, кут, 3D-модель, підказки, закритий косоур.
- Історія зберігається при кожному розрахунку; очистити можна в налаштуваннях.
